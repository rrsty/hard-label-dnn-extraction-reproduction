## 1. 实验一：全自动化端到端黑盒网络提取（核心成果）

### 1.1 实验设定
- **目标网络**：`data/unitary_32_32x3_10_float64.keras`
- **网络结构**：$32 \to 32 \to 32 \to 32 \to 10$（3 个隐藏层，ReLU 激活，双精度浮点 `float64`）
- **攻击限制**：攻击者仅能访问 `oracle.label(x)` 获取硬标签（输出类别的整数），无法获取 logits、梯度、置信度或任何真实网络参数。
- **并行配置**：8 个并发 Worker 进程。

## 2. 实验二：Leaky ReLU 神经元符号快速恢复

### 2.1 实验设定
- **目标网络**：`data/unitary_leaky_32_32x3_10_float64.keras`（负斜率 $\alpha = 0.1$）
- **特点**：在线生成决策边界点，利用 Leaky ReLU 在两侧梯度跳变的不对称性快速推导神经元正负号。

### 2.2 实验结果

仅需 20 秒即完成对全网全部 3 个隐藏层的在线推断：

```text
Hidden Layer 1/3 -> Layer: 1, Experiments: 101, Correct signs: 32/32 (100%)
Hidden Layer 2/3 -> Layer: 2, Experiments: 101, Correct signs: 32/32 (100%)
Hidden Layer 3/3 -> Layer: 3, Experiments: 101, Correct signs: 32/32 (100%)
```

- **样本数**：每层仅需 101 个边界点样本。
- **准确率**：$96 / 96$ 个神经元符号全部正确判定（**准确率 100%**）。

## 5. 结论与复现复盘

1. **完全验证了论文核心主张**：
   - 证明了在仅提供 Top-1 硬标签的极其严苛条件下，多层深层神经网络的权重、偏置与激活符号能够在多项式时间和多项式查询内被**完全重构**。
   - 实际总查询次数约 **3,866 万次**，与论文理论估算值（~4,000 万次）高度契合。
2. **精度超越预期**：
   - 在经过 `refine` 阶段后，权重重构精度达到双精度浮点极值（$10^{-14}$ 量级），测试集分类预测达成 100% 绝对一致。
3. **计算效率高效**：
   - 在普通 8 进程 CPU 并发调度下，端到端完整提取耗时仅 **6 分 36 秒**；Leaky ReLU 符号恢复仅需 **20 秒**。
